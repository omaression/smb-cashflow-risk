# Web App

Next.js dashboard for the SMB Cash Flow Risk project.

## Planned views
- overview dashboard
- invoice risk table
- customer drill-down
- cash forecast chart

## Expected API base URL
Set `NEXT_PUBLIC_API_BASE_URL`.

- Local: `http://127.0.0.1:8000/api/v1`
- Production: `https://cashflow-api.omaression.com/api/v1`
